Naïve × Hermes: setup diagrams

How each system is put together, and how they meet when Naïve runs harness: "hermes". Built from the docs snapshot of 2026-11-07; terms are defined in naive/terminology.md, hermes/terminology.md and cross-reference.md.

1 · Naïve Managed Agents

You configure the agent. Naïve operates the three layers underneath it: harness, tools, runtime.

2 · Hermes Agent

One AIAgent class serves every entry point. Plugins attach through public interfaces.

3 · Hermes inside Naïve (harness: "hermes")

Naïve runs Hermes as "an external coding agent, run as a process" on a micro-VM. Hermes owns the turn loop; Naïve owns everything beneath it.
