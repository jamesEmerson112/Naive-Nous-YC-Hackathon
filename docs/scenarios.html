Four ways to wire a sponsor into a Naïve agent

This is the weekend's biggest technical decision. Naïve's MCP connector only reaches remote HTTPS servers, using a token from its vault. An agent's config can't carry a key, and the vault can't hand one to the sandbox.

A · Self-running agency Main track

Idea: clone Naïve's agency blueprint, pick a niche, and let its seven-agent crew find clients, write proposals and keep the site fresh while you sleep.

B · Mobile app QA studio Mobilerun track

Idea: app makers send a store link; agents install it on cloud phones, run the key flows and send back a bug report with screenshots. Here the phone is the product, not a side feature.

C · Support desk as a service AgentMail track

Idea: every client business gets its own support inbox. Agents triage, answer from the client's FAQ, escalate the hard ones, and send a daily digest. Naïve's own support blueprint (template inbox) already uses this crew shape on Naïve email.

D · Market-intel report company Monid track

Idea: small businesses subscribe to a weekly report on their competitors. Research agents pull from many data providers through Monid, and a writer turns the findings into a report. The breadth of providers behind one integration is the point.

The clock: build by day, let it run overnight

The judges score what the company did without you, so the night is when your company earns its demo.

Ask on site

None of the sources answer these. Each answer can change which pattern or scenario you pick.

Mobilerun

  • What are the MCP's tool names?
  • Can our team get an iPhone?
  • Does Naïve's own mobile tool count as "use of Mobilerun"?

AgentMail

  • Does mcp.agentmail.to accept Authorization: Bearer <key>?
  • Which events do webhooks send?

Monid

  • Is there a bearer or API key for the MCP, not just OAuth?
  • Is there hackathon credit beyond the free $1?

Organizers

  • Can one company win the Main track and a sponsor track?
  • What is Stripe's "inc. fee waived"?
  • How do we get more Naïve credits?
